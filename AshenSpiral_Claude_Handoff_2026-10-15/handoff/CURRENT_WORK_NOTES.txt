Status: frozen unfinished work. Paths below are relative to the WIP project.

at export. Items explicitly called plans are not implemented.

BASELINE AND PROVENANCE
The WIP was copied from the delivered 0.22.0 project. It retains existing source
art, setup/build helpers, and older documentation. Source changes are in the
accompanying diff and machine-readable change list. The 0.23 and 0.23.1 prompt
packs were extracted into reference/0.23 and reference/0.23.1. No completed
0.23 or 0.23.1 release exists. Background work was interrupted; the frozen files,
not any worker intention or progress estimate, are the source of truth.

ASExpeditionRules.h (new engine-independent helper header)
- Difficulty 0..2. HP factors 1 / 1.5 / 2.1; damage 1 / 1.3 / 1.6;
  quality 1 + .25*difficulty. These are implementation defaults, not all wired.
- Endless W=wave-1, K=max(W-38,0). Tier rate normal=1, elite=1.25, boss=1.875.
  HP multiplier 1 + rate*(W*.09 + K*K*.008).
  Damage multiplier 1 + rate*(W*.035 + K*K*.003).
- Boss each 10 waves. Reward each wave <=20; even waves 21..50; (wave-50)%3==0
  thereafter; every boss wave also rewards. Sky 1..20 clear,21..49 gloom,50+ red.
- Anger speed starts 1.12 after 50 and caps 1.3; enemy count capped at36.
- TraitPower retains full strength through normal cap, then five-rank blocks
  at .8,.7,... down to .1. Pick count clamped to10000 as an implementation bound.
- ChoiceCount=3+rank; upgrade costs150,750. Bleed duration25sec pauses if revived.
- Wave shuffle distribution {1,2,3,3,4,4,4,5,5,6,7} averages4.
  Time shuffle120..180sec; lucky shop15% at wave>=10.
- Gambling buckets by available Ash: <=50 loss/refund/x2/x5/x10 =45/25/24/5/1%;
  >=1000 =50/20/22/7/1%; middle =60/20/17/2/1%. Multipliers include stake return.
  These odds are code defaults; UI/server transaction flow is not present.
- Synergy numeric kinds Burn2/Poison3/Frost4/Shock8: Burn+Shock=Lightning Blast,
  Frost+Shock=Stormbreak, Burn+Poison=Wildfire. Base60/45/50 * max(1,power)
  plus 3.5% boss maxHP. Needs balance/co-op tests.
- Exclusive offer IDs400..403: Bloodroot (.35 maxHP/kill/rank), Close Quarters
  (close kill3HP+2Scrap/rank), First Blood (first-hit-to-kill<1s:3Scrap/rank),
  Unbound Fury (8% primary damage/rank). These are proposed runtime rules only.
- This new header has no completed 0.23-specific regression suite.

New replicated state (ASGameState.h/cpp)
- Player: Endless unlock/choice count, available Ash/Scrap, run damage/damage
  taken/kills, shop claim flag, last gambling room.
- Game: difficulty, Endless mode/wave/highest cleared wave, lucky/rare shop flags,
  shuffle deadline. Fields are registered for replication; mode transitions and
  UI are still the prior normal-run implementation.

Save/profile work (ASData, ASGameInstance)
- FASEndlessRecord: run id, highest cleared wave, local/partner damage/kills/
  damage taken, ended UTC; sanitization added.
- Profile: BestEndlessWave, EndlessChoices0..2, up to10 sanitized/sorted records.
  Existing profile schema/migration remains schema1/migration20.
- Receipt: profile id, Endless flags/wave/end record, AshCost/ScrapCost/Scrap.
- ActiveCharacterSlot, BaseSlot, LoadCharacter and SwitchCharacterSlot added.
  Slot2 uses base save name + _Character2. Selection is stored per base slot in
  local config. Old A/B revision selection and legacy import logic retained.
- Switching only in Hub and refuses while ANY player has pending saves; attempts
  rollback on blocked target load. No controller/UI action is yet connected.
- Review fresh-slot Commit failure handling: inherited load logic may ignore
  failure to create a fresh save. Do not claim slot isolation tested.
- Purchase category9/index0 buys choice-rank for150/750; UI not connected.
- Receive rejects a mismatched ReceiptProfileId, uses existing receipt IDs for
  deduplication, debits costs, credits Scrap/Ash, records Endless results.
- CRITICAL: GameMode SendReceipt does not yet stamp the profile id. Existing
  normal rewards can therefore be rejected by the modified Receive path.
- PreviewImport rejects importing the other slot's profile identity.
- GameMode ProfileArrived still blocks changed profile IDs; permit safe Hub
  switching only and update cached/reconnect state. Do not permit combat swaps.

Boss protection / synergies / damage
- Boss BeginPlay authority starts2sec SpawnProtectedUntil; field replicated.
- Character CanDamage, Enemy Hit/Control/CommitAttack respect protection.
- Protected authority enemy Tick stops movement and shows a tell. Clients do not
  yet get a complete visible spawn sequence. Audit every damage/status path.
- Kind2 sword enemy no longer uses the ranged attack branch and closes to melee.
- Enemy Hit credits source damage, sets first engagement time, triggers reaction.
- Hero accepted damage credits run damage taken; challenge damage is multiplied
  by the new difficulty/Endless scaling rules, with default normal unchanged.
- Cross-player element markers are per enemy,3sec window,3sec global cooldown;
  consuming a synergy clears markers. Same-player combinations do not trigger.
- Synergy sends callouts to both participants, emits colored radius470 effect,
  applies area damage with line-of-sight, avoids protected targets and direct
  recursive elemental proc chains. Stormbreak also slows for2sec.
- Review ApplyElement after RegisterCoopElement: synergy may kill the current
  target before the rest of ApplyElement continues. Add/review liveness guards.
- Audit direct well SlowUntil/PulledUntil mutations so boss protection also
  prevents status/control, not just primary damage.
- Generic VFX/callouts are preliminary, not P2-approved bespoke synergy visuals.
