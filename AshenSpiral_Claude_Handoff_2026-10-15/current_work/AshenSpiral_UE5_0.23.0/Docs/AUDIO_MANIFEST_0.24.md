# Ashen Spiral 0.24 - Enemy audio manifest

Generated by `Tools/export_audio_manifest.cpp` from the cue table in `Source/AshenSpiral/Public/ASEnemyRules.h`. Do not edit by hand; change the table and regenerate.

Every enemy telegraph and every attack release has a **cue**. The game plays a cue from the replicated enemy state on every machine, at a volume that falls with
distance to the local player (full inside 6 m, silent beyond 32 m). Each cue names a file below. **Until that file exists the game plays the existing sound in the last
column at the listed pitch and volume**, so nothing is silent and nothing breaks while the real files are made.

## How to deliver a file

1. WAV, **mono, 16-bit PCM, 44.1 kHz** (`Tests/run_tests.py` rejects anything else), named exactly like the **File** column.
2. Put it in `SourceArt/Audio/`. Nothing else needs editing: the importer takes every WAV in that folder and the test counts follow the folder.
3. Run `Reimport_Source_Art.bat` (or `Setup_and_Open.bat`). The cue starts using the new file on the next launch, at its natural pitch and the listed volume.
4. Level: peak near -3 dBFS, about as loud as the existing cues (the volume column is a multiplier applied on top). No leading silence; tails under half a second
   unless the note says otherwise. A wind-up cue should be shorter than its wind-up so it ends as the attack lands.

Telegraph and release cues together are the readability rule of this update: a player should be able to tell what is coming with their eyes closed. See
`Docs/TELEGRAPH_LANGUAGE_0.24.md`.
