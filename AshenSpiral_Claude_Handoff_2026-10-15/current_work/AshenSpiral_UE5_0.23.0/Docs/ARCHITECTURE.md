# Runtime architecture

## Current 0.21 additions

Protocol 2100; profile schema 1 and migration 20 retained. `ASMeleeRules.h` owns grip/key-pose curves and combo timing; `ASMeleeCombat.cpp` schedules authority-side impacts and bounded finisher root motion. Attack interval and pose duration share the complete melee cycle. `ASMovementComponent` and reconnect snapshots retain an integer airborne dash count. `ASArchiveRules.h` supplies deterministic clearance-checked furniture plans; `ASWorldArchives.cpp` instantiates them only for biome 0. Bootstrap art revision 9 imports 78 meshes, 12 maps and eight sounds. Historical sections below describe the original additions; DESIGN_0.21.md takes precedence.

## 0.18 additions

`ASRules.h` generates 5–10 actual rooms across five topology families, with 1×1, 2×2, 2×3, 3×2 and 3×3 footprints. World coordinates account for unequal room dimensions. Solid spanning edges guarantee walking connectivity; optional gaps do not gate progress. A weighted shortest-path calculation selects the reward room. `ASWorld` places original large-room landmarks around clear crossing lanes and builds capsule-checked navigation.

`ASRouteGuide` is a nonreplicated actor owned by each local controller. After a clear it displays a thick 3D arrow near the player and smaller route chevrons. `ASWorld::GuideRoute` performs A* on the collision grid, smooths clear segments and refreshes after map or breakable changes. This grid-based route is not an exact continuous-space shortest path.

`ASPresentationRules.h` supplies quarter-step HUD scaling and notice fade timing. `ASHUD` applies local group origins/scales to compact peripheral panels, prompts and one bounded notice stack; the controller owns message ages, and the game instance immediately persists scale preferences. Existing Slate labels and separate crosshair/damage-number controls remain.

`ASArsenalRules.h` owns firing rates, pellet count, falloff and rotary heat for weapon IDs 6–8. Character code integrates firing and poses, while authoritative projectile code applies falloff and cover-tested rocket splash. Eligibility masks include the new firearms without shifting old IDs; rockets exclude piercing/ricochet/split. The bootstrap imports nine weapon meshes plus the route arrow under art revision 7. Profile schema stays 1; network protocol is 1800.

## 0.16 additions

`ASCareerRules.h` owns cosmetic XP thresholds, 12 stable achievement-counter IDs with three tiers each, status-combination eligibility and capped Cinder conversion. Default-zero XP and counter fields extend schema 1 without renaming existing fields. PlayerState records authority-side pending progress, GameMode drains it into idempotent receipts, and GameInstance commits it together with existing currencies. Cosmetic level replicates; client-reported XP does not grant combat stats. Reconnect snapshots preserve pending career data and clear eligibility. Returning to the hub freezes combat before draining progress, preventing late attacks from creating a second return receipt while the first save is pending.

GameMode banks Cinders once per cleared chamber after choices/shopping, queues personal receipts and waits for acknowledgment before advancing. Final completion skips offer generation and transitions to Victory with a world-space portal. Either nearby, active player can request the return after server reach/sight checks; the transition retains the session and waits for saves.

HUD bars/lines stay on Canvas; a volatile `SLeafWidget` paints labels with Slate fonts in a full-viewport layer and converts Canvas coordinates to local geometry coordinates. PlayerController separates permanent gameplay capture from unconfined menu input. A raised spring-arm target, wider shoulder offset, downward camera sightline and local owner-only hiding address wall compression. Actual DPI behavior, input capture and wall views need Unreal verification.

Pawn capsules block one another with no step-up or physics interaction. Routes use direct supported sweeps, clear-node lookahead and sideways crowd separation; unreachable routes hold position. Spawn and recovery points reject occupied capsules. World imports mesh-matching collision for eight new environment assets; continuous cave/barrel vaults cover clearings and passages. The cave theme occupies chambers 17–24. Material import explicitly enables instanced-static-mesh usage; sun/fill priorities differ. The expanded no-shadow point-light cap is 48. Runtime performance has not been measured.

## 0.14 additions

`ASBuildRules.h` is a second engine-independent kernel: 63 stable trait IDs, categories/tags/rarities/caps, context-aware eligibility, weighted drafts, charge/Focus refill, bleed-duration scaling, challenge tiers, swept dash contact and rotating-blade contact. `ASCharacterUpgrades.cpp` connects that kernel to authoritative damage/healing, proc limits, resources and rare picks; active ability casts now live in ASAbilities.cpp. Persistent profile fields are not expanded; traits belong to the replicated run character and reconnect snapshot.

PlayerState owns personal reward offers and pending receipt queues. GameState replicates public wager/vault status. GameMode validates rerolls, unanimous wagers, sigil/cache interactions and summon caps. Fields register for Vault Sense. World routing validates supported capsule-clear lookahead; leapers request a collision-checked ballistic shortcut. Stuck recovery remains an explicit emergency teleport to a later safe route node.

New monster, pickup and saw meshes are generated by `generate_encounter_art.py`, using the existing original mesh-building primitives. The upgrade catalog is generated directly from runtime definitions. These changes still require UnrealHeaderTool/module, importer, physics, visual and multiplayer verification.

`ASRules.h` is an engine-independent C++17 kernel used both by the Unreal runtime and the native tests. It defines seeded connected layouts, room/wave indexing, actor limits, perfect-release timing, stat upgrade math/offer selection, revive distance/timing, weapon grip/swing poses, air-dash eligibility, phase gates, elemental integration, enemy-bar fading, four-way A* and transactional currency rules. Layout tests do not exercise collision meshes or Unreal movement.

`ASData` contains the content tables and reflected profile/build/receipt structures. `ASGameInstance` owns local profile persistence, purchases, quality settings and network-failure handling. Purchases serialize SaveGame data to alternating files in a version-independent platform user-settings folder, verify a temporary file and final bytes, then update the live profile. Legacy project-local copies can migrate; export/import retains the same schema and shows a review before restore. Restore exports the current profile first. Corrupt-file preservation and stale-revision checks guard common failure cases, but there is no interprocess write lock or cloud sync. Receipts are retained for reward deduplication; long-running profiles may need receipt compaction in a production version.

`ASGameMode` is authoritative for the hub/run state machine, spawns, reward offers, progression receipts, reconnect reservations and room transitions. `ASGameState` replicates the public phase/timing/map data. `ASPlayerState` holds each player's build, readiness, claim status and owner-only offers. Peer profiles are trusted; protocol/session-code checks are not authentication.

`ASWorld` deterministically rebuilds each room on each machine from replicated room/seed parameters. It groups repeated static meshes into instanced components. World-static collision protects walls and props; bridges follow a connected graph. Architectural arches and props use complex-as-simple static collision to preserve mesh openings; distant backdrop decoration sits outside generated room bounds. Five layout families use 5–10 rooms with variable multi-cell footprints. Authority builds a floor-supported, capsule-clearance navigation grid, blocks swept edge collisions and keeps only the player-connected component. Spawn points and enemy routes use that component.

`ASCharacter` handles aim, nine weapon behaviors, charge/release, damage, revival and articulated static-mesh poses. `ASMovementComponent` implements the dash through CharacterMovement custom mode and compressed saved-move flags. Native jumping retains the base Character compressed flags alongside the custom dash flag. One airborne dash retains vertical velocity and gravity; saved moves capture used-air-dash state and vertical speed for replay. The server and local tick paths both observe the shared freeze state. The downed pawn advances its replicated revive progress after validating a helper, including in the Reward phase. Run stat ranks replicate on the character and are included in reconnect snapshots. `ASEnemy` implements grid-following chasers, ranged attackers, elites and boss variations. It integrates capped elements and damage ticks, replicates status bits and last-damage time, and supports a stationary resetting practice target with no reward path.

`ASSpell` contains projectiles, wells, area fields, pickups and local visual effects. Array copies are used when destroying registered actors during iteration. Actor lifetimes and caps bound ordinary spell/enemy populations. Projectiles, wells and fields capture practice/cosmetic eligibility when spawned. Shared phase checks and well-interaction guards prevent inter-wave effects from gaining combat benefits later. Imported materials and mesh references are resolved through `ASAssets` in the world implementation.

`ASPlayerController` routes inputs, profile submission, host commands and menus. `SASMenu` is the native Slate interface. `ASHUD` draws typed damage numbers, crit feedback, separate health/shield bars, fading small enemy bars, the fitted minimap and the frame-time overlay. Free weapon trials change the hub pawn only; expedition initialization restores the saved build. Reward advance validates either requester after every personal claim and save acknowledgment.

`Tools/bootstrap_unreal.py` is editor-only. It imports the source art, creates the shared material and saves the initial map. No editor scripting module is linked into the game's runtime module. `Tools/Common.ps1` centralizes version discovery, logging, compilation and bootstrap checks. All Windows launch/import/packaging paths require local validation.

## Safe extension points

Tune damage/cooldowns and content descriptions together; change layout constants and rerun the shared-rule tests; replace individual meshes while retaining centimeter scale and intended pivots; replace static-mesh hero poses with a skeletal mesh/animation blueprint as a dedicated animation pass. Preserve public replicated fields/RPC signatures unless both peers update together. Bump the profile schema and add explicit migration before incompatible changes to serialized save structure. In 0.12.0, the existing variable-length rank array expands from 16 to 20 via Sanitize; original positions are preserved and new positions are zero-initialized. This does not add or rename a serialized save property.
