# Content and provenance

The gameplay/content basis is the user's supplied Ashen Spiral v0.10.1 HOTFIX archive. Existing names, design and source-derived tables remain attributable to that supplied project; this file does not claim ownership over the user's pre-existing work.

The Unreal C++ implementation, setup helpers, tests and documentation were newly authored for this remake. The bundled OBJ geometry, three textures and six synthesized sound effects were generated for this package using `Tools/generate_source_art.py`. No downloaded third-party art pack or copied commercial game assets are included.

The revised weapons/practice dummy and 0.14 enemies/pickups/saw are original geometry from `Tools/generate_weapon_art.py` and `Tools/generate_encounter_art.py`. The user requested mechanics inspired by Crab Champions, RuneScape: Dragonwilds and Ember Knights; the design/reference mapping is in `BUILDCRAFT_0.14_NOTES.md`. No assets, source code, audio, logos or distinctive character models were extracted from those games, and no affiliation is claimed.

The 0.15 cave rock, crystal cluster, loot crystal, ember cask and wall nozzle are original procedural geometry from `Tools/generate_frontier_art.py`. New feature references and scope are recorded in `FRONTIER_0.15_NOTES.md`.

The 0.16 vault shells, stalagmite/stalactite, basalt column, natural floor, nurse log and lantern are original procedural geometry from `Tools/generate_restoration_art.py`. Environmental research references are documented in `RESTORATION_0.16_NOTES.md`; reference photographs are not bundled.

Unreal Engine is required separately under Epic's applicable terms. Runtime references to Unreal's BasicShapes and built-in engine fonts resolve from the user's engine installation; their binary assets and font files are not included in this ZIP. Required editor plugins are Unreal's own included plugins, not bundled external plugins.

Optional source-art regeneration uses NumPy, trimesh and Pillow in a developer Python environment. Those libraries are not copied into this project. Normal setup imports the already-generated source art using Unreal's included Python and does not require those packages.

No finished-game commercial-rights clearance is asserted for the original input's full history or any assets later added by the user. Keep this provenance record with the source project.

The 0.19 reward/skill/dice glyphs are original code-native artwork in `ASEffectArt.h`. Two additional original synthesized reload cues come from `Tools/generate_reload_audio.py`, bringing the sound total to eight. Interface and pacing references are linked in DESIGN_0.19.md. No reference-game artwork or sound recordings are included.

The 0.20 armor and creature revisions are original OBJ geometry generated by `Tools/generate_armor_art.py`, using the user's supplied image(8).png as a visual direction. They use native modular components and procedural two-bone posing, not a purchased character or mocap pack. `Tools/preview_armor.py` renders the actual source geometry with NumPy/Pillow for documentation; its pictures and GIF are not engine captures. The user's latest bugfix-decision PDF is retained with the source, alongside the earlier expansion worksheet marked deferred.

The 0.21 Archives kit contains seven original procedural meshes and nine original material maps from Tools/generate_archive_art.py. The hammer shaft is lengthened in generate_weapon_art.py. Melee curves/grips are native procedural poses. No third-party animation or reference images were bundled. P2's referenced eight-image pack and the fix-candidates file were unavailable; this pass follows the written October 14 brief. The three new preview images render source meshes/shared rules, not Unreal gameplay.
